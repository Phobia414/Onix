# Telegram Bot для разработки ботов

Асинхронный Telegram-бот на базе Aiogram 3 для приема заявок на разработку ботов.

## 📋 Функционал
- Создание заявок с выбором сложности и типа бота
- Админ-панель (смена статусов, цены, сдача работы, рассылка, портфолио)
- Реферальная система (скидка 10% за друга)
- Система блокировок и штрафов
- Отзывы в канал
